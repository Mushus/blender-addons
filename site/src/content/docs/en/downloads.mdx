## Installation Guide

1. Download the `.zip` file for your desired add-on above (do not extract the ZIP file).
2. Open Blender and go to **Edit > Preferences > Add-ons**.
3. Click the **Install...** button in the top right corner and select the downloaded ZIP file.
4. Enable the add-on by checking the checkbox next to its name.

For more details, check out the [Installation Guide](../guides/installation/).

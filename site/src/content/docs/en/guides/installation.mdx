Follow these steps to install and enable any of our Blender add-ons.

## Install from the Extensions Repository (Recommended)

On Blender 4.2+, add this remote repository under Get Extensions to install and update add-ons from the list. The repository lists **individual add-ons only** (the Suite ZIP is not included).

<Steps>

1. **Open Preferences**
   `Edit` ➔ `Preferences` ➔ **Get Extensions**

2. **Add the Remote Repository**
   1. Open **Repositories** ➔ **+** ➔ **Add Remote Repository**
   2. Paste this URL:
      `https://mushus.github.io/blender-addons/index.json`

3. **Install Extensions**
   Find the add-on in the list, then install and enable it.

</Steps>

---

## Install from a ZIP File

<Steps>

1. **Download the Add-on Zip**
   Download the `.zip` file from the respective add-on page.

2. **Open Blender Preferences**
   Launch Blender and navigate to `Edit` ➔ `Preferences` in the top menu.

3. **Install from Zip**
   1. Select the **Add-ons** tab on the left.
   2. Click the **Install...** button at the top right.
   3. Select the downloaded `.zip` file and click **Install Add-on**.

4. **Enable the Add-on**
   Search for the add-on name in the search bar and **check the checkbox** next to it to activate it.

</Steps>

## Updating / Uninstalling

### Extensions repository

Update from the Get Extensions list. To remove an extension, uninstall it from that list.

### Manual ZIP installs

To update an add-on to a newer version, we recommend removing the old version first:

1. In Preferences > Add-ons, expand the target add-on item.
2. Click **Remove**.
3. Restart Blender and install the new `.zip` file.

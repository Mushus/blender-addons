Follow these steps to install and enable any of our Blender add-ons.

## Installation Steps

<Steps>

1. **Download the Add-on Zip**
   Download the `.zip` file from the respective add-on page.

2. **Open Blender Preferences**
   Launch Blender and navigate to `Edit` ➔ `Preferences` in the top menu.

3. **Install from Zip**
   1. Select the **Add-ons** tab on the left.
   2. Click the **Install...** button at the top right.
   3. Select the downloaded `.zip` file and click **Install Add-on**.

4. **Enable the Add-on**
   Search for the add-on name in the search bar and **check the checkbox** next to it to activate it.

</Steps>

---

## Updating / Uninstalling

To update an add-on to a newer version, we recommend removing the old version first:

1. In Preferences > Add-ons, expand the target add-on item.
2. Click **Remove**.
3. Restart Blender and install the new `.zip` file.

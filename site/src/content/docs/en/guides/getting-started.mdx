This documentation portal provides installation instructions and usage guides for our Blender workflow add-ons.

## System Requirements

- **Blender Version**: Blender 4.0 LTS or newer recommended (some add-ons support 3.6 LTS+)
- **Operating System**: Windows / macOS / Linux

## Quick Start

1. Visit the **[Installation Guide](/en/guides/installation/)** to download and enable your desired add-on `.zip` file in Blender.
2. Refer to the specific add-on page to learn UI locations and controls.

For bug reports or feature requests, please submit an issue on our [GitHub Issues](https://github.com/Mushus/blender-addons/issues) page.

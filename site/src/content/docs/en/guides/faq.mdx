## Troubleshooting

### Q1. The installed add-on does not appear in the list.

- **Cause**: The `.zip` file may have been unzipped and re-compressed incorrectly, or a wrong directory was imported.
- **Solution**: Download the original `.zip` file from the official GitHub Releases page without extracting it.

### Q2. Python errors occur when enabling the checkbox.

- **Cause**: Your Blender version might be older than the required minimum version.
- **Solution**: Check the recommended Blender version on the add-on page and update Blender to 4.0 LTS or newer.

### Q3. I cannot find the add-on panel in the UI.

- **Cause**: Different add-ons place their panels in different locations.
- **Solution**: Check the **UI Location** section on the respective add-on documentation page. Most tools reside in the 3D Viewport Sidebar (opened with `N`).

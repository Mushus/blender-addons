## Overview

**In-Between Shape Key** helps riggers and animators create intermediate shape keys (in-betweens) automatically by interpolating between base and target shape keys.

---

## UI Location

- Properties Editor > **Object Data Properties** (green triangle icon) > **Shape Keys** panel specials menu.

![In-Between Shape Key properties](../../../../assets/addons/in_between_shape_key/properties.png)

---

## Features & Usage

1. Select one ordinary Shape Key and run **Convert to In-Between Shape Key**. Its original shape becomes the initial `@1` key.
2. Set the controller **Value** to the desired position, then use the down-arrow beside Value to select an existing Shape Key. The selected key is renamed to `Controller@Value`.
3. Drag a target row's slider or enter a number to move the key between `0.000` and `1.000`. The displayed value is read directly from the name, and editing it renames the key immediately (for example, `Smile@0.5`). `@.5` and `@0.500` are not recognized as In-Between targets and remain ordinary Shape Keys. An `@0` target is applied when Value is zero. The last key's shape remains constant through 100%.

`@1` is optional. During FBX export, the highest target shape is duplicated at position 1, which encodes the flat final segment through FBX 100%.

After conversion, the controller and target Shape Key values are driven and appear purple. Edit and keyframe the controller through Value in the In-Between panel.

Targets are listed in position order. Their order in Blender's standard Shape Key list does not affect membership. Use the key icon at the left to select one, or the × button at the right to delete it.

### Key Operators

| Operator                            | Description                                                                           |
| :---------------------------------- | :------------------------------------------------------------------------------------ |
| **Convert to In-Between Shape Key** | Convert an ordinary Shape Key into an in-between controller                           |
| **Add to In-Between**               | Choose an existing Shape Key in a dialog and add it at the controller's current value |

## トラブルシューティング

### Q1. アドオンをインストールしてもリストに表示されない
- **原因**: 誤って `.zip` ファイルを解凍してから再度圧縮した、または別のフォルダ階層をインポートした可能性があります。
- **対処法**: 公式 Releases ページからダウンロードしたそのままの `.zip` ファイルを指定してインストールしてください。

### Q2. チェックボックスを入れると Python エラーが発生する
- **原因**: お使いの Blender バージョンが対応バージョンより古い可能性があります。
- **対処法**: 各アドオンページの推奨 Blender バージョンをご確認の上、最新の Blender（4.0 LTS 以上推奨）にアップデートしてお試しください。

### Q3. パネルが画面上に見つからない
- **原因**: アドオンによってメニューやタブの配置場所が異なります。
- **対処法**: 各アドオンの個別ページにある「**UIの配置場所**」の項目をご確認ください。多くのツールは 3D ビューポートの `N` キーで開くサイドバー内に配置されています。

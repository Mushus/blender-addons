Blender アドオンをインストールし、有効化するまでの基本的な手順です。

## 拡張リポジトリからインストール（推奨）

Blender 4.2 以降では、Get Extensions にリモートリポジトリを追加すると、一覧からのインストールと更新ができます。リポジトリに載るのは**個別アドオン**のみです（Suite ZIP は対象外）。

<Steps>

1. **プリファレンスを開く**
   `編集 (Edit)` ➔ `プリファレンス (Preferences)` ➔ **Get Extensions**

2. **リモートリポジトリを追加**
   1. 右上のリポジトリメニューから **Repositories** ➔ **+** ➔ **Add Remote Repository**
   2. URL に次を貼り付けます:
      `https://mushus.github.io/blender-addons/index.json`

3. **拡張をインストール**
   一覧から目的のアドオンを選び、インストールして有効化します。

</Steps>

## ZIP から手動インストール

<Steps>

1. **アドオン Zip ファイルの入手**
   各アドオンページの「ダウンロード」ボタンから、目的のアドオンの `.zip` ファイルをダウンロードします。

2. **Blender のプリファレンスを開く**
   Blender を起動し、上部メニューの `編集 (Edit)` ➔ `プリファレンス (Preferences)` を開きます。

3. **アドオンタブを選択し Zip を指定**
   1. 画面左側の **「アドオン (Add-ons)」** タブを選択します。
   2. 右上の **「インストール... (Install...)」** ボタンをクリックします。
   3. ダウンロードした `.zip` ファイルを選択し、「アドオンをインストール」をクリックします。

4. **アドオンの有効化**
   検索バーにアドオン名を入力し、表示されたアドオンの**チェックボックスをオン**にして有効化します。

</Steps>

## アンインストール・更新手順

### 拡張リポジトリ経由

Get Extensions の一覧から更新できます。手動削除する場合は、対象拡張を選んでアンインストールします。

### ZIP 手動インストールの場合

アドオンを更新する場合は、一度古いバージョンを**削除 (Remove)** してから新しい `.zip` をインストールすることを推奨します。

1. プリファレンス > アドオン設定から対象のアドオンを展開します。
2. **「削除 (Remove)」** ボタンをクリックします。
3. Blender を再起動し、新しい `.zip` ファイルをインストールしてください。

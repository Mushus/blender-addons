このサイトでは、Blender ワークフローを拡張・高速化するためのアドオンの入手方法および使い方を解説しています。

## サポート環境

- **Blender バージョン**: Blender 4.0 LTS 以降推奨（※アドオンにより 3.6 LTS 以降にも対応）
- **OS**: Windows / macOS / Linux

## はじめかた

1. **[インストールガイド](../installation/)** を確認し、お目的のアドオン `.zip` を Blender に登録・有効化します。
2. 対象アドオンの解説ページを参照し、UIの表示位置や操作方法を確認してください。

各アドオンの修正依頼や機能提案は [GitHub Issues](https://github.com/Mushus/blender-addons/issues) より受け付けています。

## 概要

**Slide Relax** は、編集モードにおいて指定した頂点群の密度・配置を滑らかに緩和（リラックス）するアドオンです。
ハイポリメッシュのトポロジー調整や、有機的モデルの表面のスムージング作業を高速化します。

```mermaid
flowchart TD
  Sel["選択頂点群"] --> Lap["近傍頂点の平均座標を計算<br/>(Laplacian 変位)"]
  Lap --> Tangent["法線成分を除去<br/>(接線平面へ投影し厚み・形状を維持)"]
  Tangent --> Check{"Preserve Boundaries?"}
  Check -->|有効| Filter["境界の内向き変位を除去<br/>(輪郭の縮みを防止)"]
  Check -->|無効| Apply["変位 × Strength を座標に適用"]
  Filter --> Apply
  Apply --> Loop{"Iterations 完了？"}
  Loop -->|いいえ| Lap
  Loop -->|はい| Result["形状を保ったまま<br/>トポロジーを均等・滑らかに緩和"]
```

---

## UIの配置場所

3D ビューポート > 編集モード (Edit Mode) > サイドバー (`N` キー) 内の `Edit` タブに配置されます。

![Slide Relax サイドバー](../../../assets/addons/slide_relax/sidebar.png)

## 主な機能と使い方

1. 編集モードでリラックスさせたい頂点（またはエッジ/面）を選択します。
2. サイドバーの **Slide Relax** ボタンをクリックします。
3. Strength / Iterations / Preserve Boundaries で強度と境界の扱いを調整します。

### 主なパラメータ

| パラメータ              | 説明                                             |
| :---------------------- | :----------------------------------------------- |
| **Strength**            | 1 回あたりの接線方向への緩和量（0.0 〜 1.0）     |
| **Iterations**          | リラックス処理の繰り返し回数                     |
| **Preserve Boundaries** | 境界頂点の内向き移動を抑え、輪郭の収縮を防ぎます |

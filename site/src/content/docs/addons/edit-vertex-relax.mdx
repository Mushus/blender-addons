## 概要

**Edit Vertex Relax** は、編集モードにおいて指定した頂点群の密度・配置を滑らかに緩和（リラックス）するアドオンです。
ハイポリメッシュのトポロジー調整や、有機的モデルの表面のスムージング作業を高速化します。

---

## UIの配置場所

3D ビューポート > 編集モード (Edit Mode) > メッシュメニュー、またはサイドバー (`N` キー) 内の `Edit` タブに配置されます。

---

## 主な機能と使い方

1. 編集モードでリラックスさせたい頂点（またはエッジ/面）を選択します。
2. 3D ビューポート内でコンテキストメニュー（右クリック）を開くか、サイドバーの **Vertex Relax** ボタンをクリックします。
3. 画面左下に表示されるオペレータパネルで繰り返し回数やスムーズ強度を微調整します。

### 主なパラメータ

| パラメータ | 説明 |
| :--- | :--- |
| **Iterations** | リラックス処理の繰り返し回数（数値が大きいほど均等化されます） |
| **Factor** | リラックスの適用強度（0.0 〜 1.0） |
| **Keep Boundary** | 外周境界の頂点位置を固定したまま内部のみを緩和します |
